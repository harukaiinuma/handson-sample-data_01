# handson-sample-data_01

こちらはハンズオンに使うための資料です。

---

## 📥 事前準備

### 1. データのダウンロード

以下のリポジトリとプロンプトをダウンロードしてください。

```
https://github.com/harukaiinuma/handson-sample-data_01.git
```

ダウンロードしたデータは**デスクトップに配置**してください。

---

## 📋 タスク一覧

### ✅ タスク1：名刺のスキャン・文字起こし → Excel出力

1. デスクトップに配置した `cards` フォルダー内の名刺画像をすべてスキャンする
2. 各名刺の情報を文字起こしする
3. 文字起こしした内容をExcelにまとめる

---

### ✅ タスク2：レシートのスキャン・文字起こし → ファイル名変更 → Excel出力

1. `receipts` フォルダー内のレシート画像をすべてスキャンする
2. 各レシートの内容を文字起こしする
3. ファイル名を以下の形式に変更する

   ```
   yyyymmdd_正しがき_アテナ.png
   例）20240101_正しがき_アテナ.png
   ```

4. 文字起こしした内容をExcelにまとめる
